# SWYNEX Git Workflow and Project Baseline

## Overview
This project demonstrates a basic Git workflow and a simple
Python calculator application.

## Project Objectives
- Understand Git and GitHub repositories.
- Practice commits and branching.
- Use a .gitignore file.
- Document a sample application.
- Follow a basic feature-branch workflow.

## Project Structure
- calculator.py: Python calculator application
- .gitignore: Files excluded from version control
- README.md: Project documentation

## Requirements
- Python 3 installed
- Git 

## How to Run
Open a terminal in the project directory and run:

python calculator.py

List the arithmatic operation first and asking to select the option from user 
based on the option opted proceeding the arithmatic function

## Git Workflow
The main branch contains the stable project.
New features should be developed in feature branches
and merged through pull requests.

## Learning Outcome
This project helped me practise repository setup,
project documentation, commit messages, and Git branching.
